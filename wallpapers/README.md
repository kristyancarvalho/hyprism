# Included wallpapers

These small original PNG wallpapers are included solely as palette-test assets. Their SVG sources are retained for attribution and editing, while the picker deliberately uses the PNG files so Matugen always receives a supported raster input. They cover blue, purple, green, and warm orange/red palettes without redistributing third-party artwork. Add personal PNG, JPEG, or WebP files to `~/Imagens/Wallpapers`; the picker and random action use that directory.
